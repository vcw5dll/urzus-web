# URZUS Snap R — сайт-презентация

Статичный сайт без сборки и зависимостей: обычные HTML, CSS и JavaScript.

## Как открыть
Распакуйте архив и дважды кликните `index.html`. Для шрифтов нужен интернет (Google Fonts); без него сайт покажет системные шрифты.

## Как опубликовать
- **Vercel:** Add New → Project → перетащите папку. Build Command и Output Directory оставьте пустыми.
- **GitHub Pages:** загрузите содержимое папки в корень репозитория (Add file → Upload files) и включите Pages (Settings → Pages → Deploy from a branch → main → / root).
- **Netlify Drop:** перетащите папку в окно браузера.

## Структура
- `index.html` — разметка и тексты.
- `css/style.css` — оформление и адаптивность (цвета и шрифты — в `:root` в начале файла).
- `js/main.js` — анимация разборки, меню, появление блоков. Тексты слоёв и характеристики — в начале файла.
- `img/` — изображения в WebP (около 0,5 МБ вместо 5,6 МБ).

## Как работает разборка
Секция «Конструкция» закреплена на экране, пока идёт прокрутка. Первая половина — клавиатура разбирается из собранного вида. Вторая половина — по очереди подсвечиваются шесть слоёв; можно нажать на номер слоя или на подпись рядом с клавиатурой.

## Перед публикацией
- Проверьте права на использование фотографий.
- Сверьте характеристики с документацией производителя (в источниках встречаются 45 г и 48 г для силы срабатывания — сноска на странице сохранена).
- Exploded view — презентационная визуализация, а не заводской чертёж.
